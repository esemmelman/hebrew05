# Hebrew vowels

A white-screen reference grouping Hebrew vowel signs by their five shared sounds in modern Israeli pronunciation. Toggle the sample aleph on or off. No dependencies or build required; open `index.html`.

Reference: University of Texas, [Biblical Hebrew Grammar for Beginners: Vowels](https://hebrew.laits.utexas.edu/drupal/themes/hebrewgrid/bh/bhonline/grammar/vowels.pdf).

Published at https://esemmelman.github.io/hebrew05/
