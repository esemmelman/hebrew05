# Hebrew vowels

A white-screen reference grouping Hebrew vowel signs by their sound groups. Six vertical columns show large vowel signs beneath an English sound and example word, with Tsere shown separately as “ai” as in “say.” No dependencies or build required; open `index.html`.

Reference: University of Texas, [Biblical Hebrew Grammar for Beginners: Vowels](https://hebrew.laits.utexas.edu/drupal/themes/hebrewgrid/bh/bhonline/grammar/vowels.pdf).
